# Changelog

## 0.4.1 - 2026-10-04

### 新增

- 界面：新增低饱和灰蓝配色的抽象企鹅适配器图标，用于插件列表、详情和配置页面。
- 头像：新增 `adapter.avatar.get` 用户和群头像查询接口，与 SnowLuma 协议一致，支持数字 ID 及已绑定数字 ID 的 OpenID，返回资源 URL 与有效期供宿主统一缓存。

### 修复

- 禁言、撤回工具默认启用，未填写 `allowed_groups` 或留空时允许所有群使用；保留显式关闭开关与非空群白名单限制。

## 0.4.0 - 2026-10-01

### 新增

- 出站支持图片与表情。
- 混合消息（文本、@、图片）按原顺序拆成多条发送。
- 出站 @ 可渲染为真实 @。

### 修复

- 修复入站消息中 @ 与文本的穿插顺序丢失的问题。

### 变更

- 优化发送失败时的错误信息。
- 更新插件描述与 README。
